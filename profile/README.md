## Quick Start with FlyOOBE

1. **Prepare your Windows 11 USB** — Create a bootable Windows 11 installation drive using the official Media Creation Tool or Rufus.
2. **Add FlyOOBE** — Copy the `FlyOOBE.exe` file to the root of your Windows 11 USB drive or a separate helper USB.
3. **Boot from the Windows 11 installer** — Start your PC from the Windows 11 USB and proceed through the initial language selection screens.
4. **Launch FlyOOBE** — When you reach the Windows 11 FlyOOBE screen (the "Let's connect you to a network" page), press `Shift + F10` to open Command Prompt, type `A:\FlyOOBE.exe` (adjust drive letter as needed).
5. **Select your preferences** — In the FlyOOBE interface, choose your desired options for Windows 11 hardware requirement checks, telemetry configuration, and system component management.
6. **Apply and continue** — Click "Apply" in FlyOOBE. The tool modifies the Windows 11 setup environment according to your selections. Close FlyOOBE and continue with the standard Windows 11 installation.
7. **Complete Windows 11 setup** — Proceed through the remaining Windows 11 FlyOOBE screens. Your preferences remain active for the duration of the installation.

## Understanding FlyOOBE Core Components

FlyOOBE is not just a simple script. It is a dedicated assistant for the Windows 11 Out-Of-Box Experience that combines several useful capabilities:

- **Hardware requirement management** — Adjusts how Windows 11 FlyOOBE evaluates TPM and Secure Boot during compatibility checks.
- **Telemetry preference configuration** — Modifies the appropriate registry keys before the first user account is created in Windows 11.
- **System component management** — Helps manage which optional Windows 11 features and pre-installed applications remain available after setup.
- **OOBE navigation assistance** — Provides a clean interface alongside the standard Windows 11 FlyOOBE screens without replacing them.
- **Offline operation** — FlyOOBE works entirely during Windows 11 setup without requiring an active internet connection.
- **Silent mode** — Advanced users can run FlyOOBE with command-line parameters for automated Windows 11 deployments.

All these work together seamlessly. You never need to search for multiple guides or registry tweaks when using FlyOOBE for Windows 11.
